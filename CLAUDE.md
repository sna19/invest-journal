# Контекст проекта для Claude Code

## Что это
«Журнал гипотез» — личное приложение владельца: инвест-гипотезы из статей, автоматический подсчёт результата против
бенчмарка и статистика, каким источникам можно верить. Один пользователь, интерфейс на русском, прежде всего iPhone (PWA).

## Рабочий канал и спецификация
https://claude.ai/artifact/6KGsL3daoaAop1699PMs21 — документ Claude Docs со спецификацией v0.1 (разделы 1–14).
Читается через коннектор Claude Docs. Этапы и критерии приёмки — раздел 11; после этапа агент пишет отчёт в этот документ.
Открытые вопросы — раздел 12 и конец раздела 14: агент работает по решению по умолчанию, пока владелец не ответил иначе.

## Документы
- docs/STAGE0.md — проверка источников данных, стек, замеры
- docs/DECISIONS.md — принятые решения (не пересматривать без явной просьбы)

## Среда
- Хостинг: Docker на NAS, свой контейнер приложения + отдельный контейнер PostgreSQL (compose и порт — у владельца).
- Образец по структуре и правилам — приложение 1% (`/work/one-percent`); общие правила платформы — `/work/CLAUDE.md`.
- Данные приложения (сырые ответы поставщиков, резервные копии) — в `/data`.

## Соглашения
- Документация и обсуждение — на русском. Код, идентификаторы, коммиты — на английском.
- Новое решение → запись в docs/DECISIONS.md (дата, решение, причина).
- Маленькие шаги, рабочее состояние после каждого коммита.
- Никаких секретов в репозитории; ключи — только в `.env` (в .gitignore).
- Журнал за годы — главная ценность: миграции без потери данных, резервная копия обязательна.
- Мобильный интерфейс в приоритете; светлая и тёмная тема; раздел 13 спецификации действует с этапа 1.

## Команды
```sh
node scripts/probe-data.mjs [--burst]   # этап 0: проверка списков и цен с NAS
```
