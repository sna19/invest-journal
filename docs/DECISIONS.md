# Принятые решения

- 2026-11-14 — Список TASE — поисковый индекс сайта биржи (`api.tase.co.il/api/content/searchentities`, вариант Б): даёт номер бумаги, символ, ISIN, имена на английском и иврите. Data Hub (вариант А) не используется, пока хватает Б; запасной путь — CSV. — Работает с NAS без регистрации; остальные адреса сайта закрыты защитой.
- 2026-11-14 — Цены — Yahoo Finance chart API напрямую из Node, без `yfinance`. Дивиденды и сплиты — из того же ответа. Цены TASE — в агоротах (`ILA`), единица берётся из ответа поставщика. — Один язык в образе; 10 лет по сотням бумаг грузятся за секунды, лимитов не встретили.
- 2026-11-14 — Стек — как в 1%: SvelteKit, SQLite (WAL), Drizzle, vitest, Lucide, PWA; два файла базы `app.db` и `market.db`; задания — node-cron внутри приложения; резервные копии через `VACUUM INTO`. — Решение владельца (раздел 15 спецификации): на NAS 4 ГБ памяти, PostgreSQL отложен.
- 2026-11-14 — Строки Yahoo без цены (пятницы TASE до 2 января 2026, когда биржа торговала вс–чт) отбрасываются; торговый календарь — по фактическим дням индекса. — Иначе появятся ложные пропуски.
- 2026-11-14 — Состав S&P 500 — ежедневный файл SPY от State Street, запасной — CSV `datasets/s-and-p-500-companies`; ТА-125 — ручной CSV, пока нет ключа TASE Data Hub. — Сайт TASE закрывает данные индексов защитой; круг 2 нужен не раньше конца этапа 3.
- 2026-11-15 — Справочник США включает и NYSE Arca, и Cboe BZX (Q-002). — Ручной ввод тикера запрещён: ETF, которого нет в справочнике, нельзя записать в гипотезу; на объём цен это не влияет, цены грузятся только по кругам.
- 2026-11-15 — Круг 2: для Израиля — все акции TASE из справочника (531), для США — состав S&P 500 по файлу SPY; состав ТА-125, ручной CSV и ключ Data Hub не нужны (Q-003). Заменяет решение от 14.11 про ТА-125.
- 2026-11-15 — Этап 2: запрет правки ключевых полей, запрет удаления и окно отмены 24 часа стоят триггерами в самой SQLite (`drizzle/app/0002_lock_hypotheses.sql`), а API дополнительно принимает в PATCH только заметку, теги, вывод и причину закрытия (иначе 409). — Критерий «не меняются ни через интерфейс, ни через API»: защита не зависит от кода.
- 2026-11-15 — Цена входа на этапе 2 не берётся: гипотеза сохраняет дату входа (сегодня по Израилю) и бенчмарк своего рынка, цена — «ожидает цену» до задания этапа 3; цену входа и бенчмарка триггер разрешает записать один раз. — Задача T-004.
- 2026-11-15 — «Новость» всегда получает direction_source «моё толкование» — и в форме, и на сервере, что бы ни пришло в запросе. Индексы-бенчмарки в форму не предлагаются. Срок по умолчанию и режим «симуляция» ставятся каждый раз, а не «как в прошлой гипотезе» (раздел 17 главнее раздела 13). — Раздел 17.
- 2026-11-15 — Отмена гипотезы — сразу, без «Вы уверены?», с полосой «Отменить» на 5 секунд (возврат в открытые в пределах тех же 24 часов). Досрочное закрытие (жест влево и кнопка в карточке) показано, но включается с ценами на этапе 3. Кнопка «+» прячется, пока страница прокручивается вниз, и возвращается при прокрутке вверх и в конце страницы. — Раздел 13 и замечание к этапу 1.
- 2026-11-15 — Заголовок статьи подтягивается с её страницы (og:title или title, до 5 с); сайты с пейволом (Barron's, WSJ) роботу обычно отказывают — тогда поле остаётся пустым и заполняется по желанию. — Раздел 13, без лишних зависимостей.
