# Проверка без подглядывания

**Что это.** Чтобы оценить модель на прошлом честно, кандидаты выбираются только по 7 годам **до** проверяемого года и измеряются в нём. Год, на котором проверяют, в отборе не участвовал. Так делается для каждого из трёх последних лет.

**Идея.** Проверка на годах, которых отбор не видел, — единственная честная оценка того, что будет дальше.

**Как пользоваться.**

**Как читать.** «Они» — средний результат выбранных в проверяемом году, «Все» — средний результат всей выборки в том же году. Если выбранные стабильно лучше всех, отбор что-то находит.

**Осторожно.** В базе нет акций, которые исчезли за эти годы (банкротства, поглощения), поэтому прошлое выглядит лучше, чем было. Проверка — только для справки. В рейтинг модели идут лишь гипотезы, записанные вперёд.

**Напоминание.** Работало ли это на годах, которых модель не видела?

**Ловушка.** Судить о модели по годам, на которых она отбирала.
