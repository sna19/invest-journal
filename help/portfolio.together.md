# Всё вместе

**Что это.** Сумма всех реальных портфелей в одной валюте (по умолчанию в шекелях) по сегодняшнему курсу Банка Израиля — с подписью «по курсу на дату». Валюта итога переключается сверху.

**Идея.** Риск и результат считаются по всем деньгам вместе: два портфеля с одной ставкой — одна ставка.

**Как пользоваться.** Для долларового портфеля — ещё одна строка: сколько стоят его доллары в шекелях сейчас и сколько стоили бы по курсу ваших собственных конвертаций. Разница — то, что дал (или забрал) курс доллара.

Экран только складывает: в самих портфелях ничего не меняется, их доходность остаётся в их валюте.

**Напоминание.** Сколько у меня всего и где?

**Ловушка.** Смотреть на портфели по отдельности и не видеть общей концентрации.
