# Tags

**What it is.** Coloured labels of entries. System ones are set by the links: a security, an ETF, an index, a sector, a portfolio, a model run, hypotheses. Personal ones you create yourself, right in an entry.

**The idea.** Tags gather entries by topic across securities and time: «reports», «entry mistakes», «macro». The cloud with counts shows what you write about most.

**How to use it.** In the cloud above the feed tap one or several tags — the entries with all of them stay. Frequent tags are on top, rare ones under «more».

**Reminder.** One tag — one topic.

**Trap.** Creating a new tag for every entry: the cloud turns into noise.
