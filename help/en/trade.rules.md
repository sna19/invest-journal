# My rules

**What it is.** Your own set of rules. The first three: 1) no exit condition, no trade; 2) a model's trade is carried out by the model in full, entry and exit included; 3) speculation only from the play budget.

**The idea.** Rules are written in calm and kept under stress. Each rule was born from a real mistake.

**How to use it.** Run your eyes over the list before every purchase. A mistake repeated twice — add a rule.

**Reminder.** A rule that is not kept is a wish.

**Trap.** Making an exception «just this once».
