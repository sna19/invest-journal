# Placebo

Among thousands of shares there are always some that rose in one quarter almost every year — by plain chance, like a run of heads in coin tosses. To tell seasonality from luck, the model repeats the same calculation 100 times on data where the quarters inside each year are shuffled. There is no seasonality there by definition. **Example:** «The real calculation found 60 shares, the placebo — 48 on average». So most of what was found is luck, and there are a dozen or two seasonal shares among them, and which ones is unknown. «Signal» — the real calculation finds clearly more than almost any placebo. «Looks like chance» — as many as the placebo. And even with a «signal» some candidates are still random.
