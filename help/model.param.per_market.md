# Не больше из рынка

**Что это.** Сколько кандидатов может быть из одного рынка — США или Израиля.

**Идея.** Один рынок может провалиться целиком; ограничение не даёт кандидатам сложиться в одну ставку на страну.

**Как пользоваться.** Меньше — список делится между рынками ровнее. Больше — допускает, что все лучшие окажутся на одной бирже. По умолчанию 7.

**Напоминание.** Не ставлю ли я на одну страну?

**Ловушка.** Убирать ограничение, потому что в одном рынке кандидаты «лучше».
