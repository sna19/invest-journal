# Сортировка

**Что это.** По какому числу упорядочиваются бумаги, прошедшие фильтр. **Среднее** — за все годы, но его может вытянуть один исключительный год.

**Идея.** Среднее любит выбросы, медиана — типичный год, худший год — устойчивость. Выбор сортировки — выбор, чего ты боишься.

**Как пользоваться.** **Медиана** — устойчивее к одному выбросу. **Худший год** — выше бумаги, у которых даже плохой год был терпимым. По умолчанию среднее.

**Напоминание.** Важен средний год или худший?

**Ловушка.** Сортировать по среднему, когда его сделал один удачный год.
