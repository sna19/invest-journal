# Выход по тренду

**Что это.** Досрочная продажа внутри квартала, если месячное закрытие ниже 3-месячной средней.

**Идея.** Стоп по тренду режет большие провалы, но в боковике выбивает из позиций, которые потом растут. Ты платишь частью дохода за меньший риск.

**Как пользоваться.** В таблице сравнения реши, что важнее: превышение или худший квартал. Выбрал — исполняй без исключений.

**Напоминание.** Выход решается до входа.

**Ловушка.** Отменять сработавший выход «на этот раз».
