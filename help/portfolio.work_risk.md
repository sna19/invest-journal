# Риск работы

**Что это.** Сектор работодателя рядом с долей этого сектора в портфеле.

**Идея.** Зарплата — тоже актив, и он в отрасли работодателя. Портфель должен уравновешивать риск работы, а не удваивать его: плохой год для этой отрасли бьёт и по доходу, и по сбережениям.

**Как пользоваться.** Держи долю сектора ниже лимита. При превышении новые деньги идут в другие секторы.

**Напоминание.** Плохой год для отрасли работы ударит дважды.

**Ловушка.** Считать знание отрасли по работе преимуществом и нагружать тот же сектор.
