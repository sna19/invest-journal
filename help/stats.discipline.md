# Дисциплина

**Что это.** Доля сделок по правилам и их результат против сделок вне правил; результат по виду сделки.

**Идея.** Правила должны доказать свою пользу числами — на твоих собственных сделках, а не в книгах.

**Как пользоваться.** Раз в квартал. Сделки вне правил хуже — аргумент себе держаться правил. Лучше на большой выборке — пересмотри правило.

**Напоминание.** Правила проверяются числами.

**Ловушка.** Делать выводы по 3–5 сделкам.
