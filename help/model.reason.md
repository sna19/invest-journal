# Метки причины

**Что это.** Сезонность, у которой есть объяснение, повторяется чаще, чем случайная.

**Идея.** Сезонность с экономической причиной (отчёт, дивиденд, сезон отрасли) повторяется надёжнее, чем совпадение.

**Как пользоваться.** «Отчёт» — компания публикует отчёт в этом квартале, и рост может быть связан с ним. «Дивиденд» — в квартале есть дата дивиденда. «Сектор сезонен» — в этом квартале обгоняет рынок весь сектор бумаги, а не только она. Метка не доказывает причину, но делает её правдоподобной.

**Напоминание.** Есть ли у сезона причина?

**Ловушка.** Считать метку доказательством: она — объяснение, а не проверка.
