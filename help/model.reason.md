# Метки причины

Сезонность, у которой есть объяснение, повторяется чаще, чем случайная. «Отчёт» — компания публикует отчёт в этом квартале, и рост может быть связан с ним. «Дивиденд» — в квартале есть дата дивиденда. «Сектор сезонен» — в этом квартале обгоняет рынок весь сектор бумаги, а не только она. Метка не доказывает причину, но делает её правдоподобной.
