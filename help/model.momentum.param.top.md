# Сколько стран (N)

**Что это.** Сколько лучших стран держать равными долями.

**Идея.** Одна страна — сильнее эффект, но и сильнее риск одной страны. 3–4 — разумная середина.

**Как пользоваться.** Смотри, как с N меняются «Худшее падение» и Sharpe, а не только доходность.

**Напоминание.** Разнообразие — бесплатная защита.

**Ловушка.** N = 1 по красивой истории.
