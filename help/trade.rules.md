# Мои правила

**Что это.** Твой свод правил. Первые три: 1) нет условия выхода — нет сделки; 2) сделка по модели исполняется по модели целиком, включая вход и выход; 3) спекуляции — только из игрового бюджета.

**Идея.** Правила пишутся в спокойствии, а исполняются в стрессе. Каждое правило родилось из настоящей ошибки.

**Как пользоваться.** Перед каждой покупкой пробеги список глазами. Ошибка повторилась дважды — добавь правило.

**Напоминание.** Правило без исполнения — пожелание.

**Ловушка.** Делать исключение «всего один раз».
