# Разбор позиций

**Что это.** По каждой открытой позиции — тезис, ответ «купил бы сегодня по этой цене?» и условие выхода.

**Идея.** Держать позицию — значит каждый день заново её покупать. Рынку безразлично, по какой цене ты покупал: цена покупки — невозвратные затраты.

**Как пользоваться.** Раз в квартал пройди все позиции. Ответ «нет» → в тот же день продать или записать новый тезис с условием выхода.

**Напоминание.** Купил бы сегодня по этой цене?

**Ловушка.** «Подожду, пока вернётся в ноль».
