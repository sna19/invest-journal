# Моя позиция

**Что это.** Блок сверху карточки бумаги: портфель, количество, стоимость, изменение за день и с покупки, срок владения, условия сделки и вся история позиции — с карандашом, отменой, сторно, «Купил», «Продал» и удалением. Если бумага есть в нескольких портфелях — по блоку на каждый, сверху тот, из которого открыли.

**Идея.** Решение о позиции принимается рядом с графиком, новостями и данными бумаги, а не в отдельном списке. Одна карточка — из портфеля, из модели, из гипотезы и из уведомления.

**Как пользоваться.** Тап по позиции в портфеле открывает карточку бумаги. Сначала смотри «Условия сделки» и сигналы, потом график и «Почему двигается». Закрытые позиции — в разделе «Закрытые позиции» внизу карточки.

**Напоминание.** Купил бы сегодня по этой цене?

**Ловушка.** Смотреть только на «с покупки» и держать позицию ради возврата к цене входа.
