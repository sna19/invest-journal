# Когда обновляются цены

Цены закрытия загружаются раз в день, утром по Израилю (по умолчанию в 07:15, время меняется в «Ещё» → «Настройки» → «Обновление данных»): за прошедший торговый день бирж США и TASE.

**Поэтому** результат показан «на дату» — последний торговый день, за который есть цена, а не на сейчас. Внутри дня цифры не меняются.

**Свежая гипотеза.** Цена входа — закрытие дня записи (или ближайшего торгового дня). Пока последняя цена — тот же день, результат равен нулю по определению, поэтому вместо «0,0%» написано «первый результат — завтра».
