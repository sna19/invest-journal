# Теги

**Что это.** Цветные метки записей. Системные ставятся сами по связям: бумага, ETF, индекс, сектор, портфель, прогон модели, гипотезы. Личные ты создаёшь сам, прямо в записи.

**Идея.** Теги собирают записи по теме сквозь бумаги и время: «отчёты», «ошибки входа», «макро». Облако со счётчиками показывает, о чём ты пишешь чаще всего.

**Как пользоваться.** В облаке над лентой нажми один или несколько тегов — останутся записи, где есть все выбранные. Частые теги — сверху, редкие под «ещё».

**Напоминание.** Один тег — одна тема.

**Ловушка.** Заводить новый тег на каждую запись: облако превращается в шум.
