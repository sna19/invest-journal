# Без последнего месяца

**Что это.** Рост считается до конца позапрошлого месяца — последний месяц пропускается.

**Идея.** За один месяц цены часто откатывают назад; без последнего месяца сигнал меньше путается в этом шуме. Так делают в большинстве исследований моментума.

**Как пользоваться.** По умолчанию включено. Выключи, чтобы увидеть разницу в «Результате».

**Напоминание.** Вчерашний рывок — не тренд.

**Ловушка.** Решать по одному месяцу.
