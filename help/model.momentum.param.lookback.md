# Рост за L месяцев

**Что это.** Сигнал страны — рост её фонда за L месяцев по ценам конца месяца с дивидендами. Классика — 12.

**Идея.** Короткое окно быстрее ловит смену лидера, но чаще ошибается и больше торгует; длинное спокойнее, но опаздывает.

**Как пользоваться.** Поменяй L — таблица пересчитается сразу, без сохранения. Сохраняй, только если решил торговать по-новому.

**Напоминание.** Меняешь правило — меняешь эксперимент.

**Ловушка.** Взять L, при котором прошлое лучше всего.
