# Оценка наблюдения

**Что это.** Наблюдение в дневнике гипотезы отмечается: тезис усиливается, ослабевает или без изменений. Гипотеза при этом не меняется — её ключевые поля закрыты.

**Идея.** Гипотеза проверяется к сроку, но по пути видно, куда идёт тезис. Цепочка «усиливается → ослабевает → ослабевает» видна заранее, а не задним числом.

**Как пользоваться.** В карточке гипотезы — «Дневник гипотезы» → «Записать»: откроется наблюдение с тремя кнопками оценки. Из любой записи можно сделать гипотезу — «→ Гипотеза»: источник «Собственная идея», текст записи станет тезисом, запись и гипотеза будут связаны.

**Напоминание.** Тезис стал сильнее или слабее?

**Ловушка.** Отмечать «усиливается» каждый раз, когда цена растёт.
