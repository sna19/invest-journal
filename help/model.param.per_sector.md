# Не больше из сектора

**Что это.** Сколько кандидатов может быть из одного сектора. Меньше — шире разброс, и один отраслевой провал не утянет весь список.

**Идея.** Бумаги одного сектора падают вместе; ограничение делает список разнообразнее.

**Как пользоваться.** Больше — список ближе к «лучшим по цифрам», даже если все они из одной отрасли. По умолчанию 2.

**Напоминание.** Сколько у меня одной и той же ставки?

**Ловушка.** Снимать ограничение и получить пять бумаг одного сектора — одну ставку пять раз.
